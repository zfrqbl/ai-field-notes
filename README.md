# Agent Builder Log

Technically dense, no-fluff notes for junior and mid-level engineers on
building, shipping, and maintaining AI-enabled apps — written by Zafar Iqbal
from real encounters while delivering agents to internal and external users.

## Structure

- `notes/` — the notes, numbered `#01`, `#02`, … (`<NN>-<slug>.md`)
- `notebooks/` — interactive Jupyter companions per note (`<NN>-<slug>.ipynb`)
- `research/` — the living extended problem list (URL-backed)
- `assets/` — diagrams and images

## Cadence

1 note per week, each with 3 LinkedIn companion posts from different angles.
